- `task1.py` — аналіз економічних показників (GDP per capita, Population) за 2019 рік за допомогою бібліотеки `pandas`.

- `task3_nltk.py` — токенізація, очищення від стоп-слів та лематизація тексту `austen-emma.txt` за допомогою `nltk` із побудовою частотних діаграм.
- `gdp_per_capita_2019.csv`, `analyzed_gdp_2019.csv`, `comptage_velo_2018.csv` — вхідні та результуючі набори даних.
